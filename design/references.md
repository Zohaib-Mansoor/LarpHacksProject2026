# Inspiration references and calibration prompts

Calibrate principles — never copy layouts, copy, graphics, or code.

- [Wise landing](https://wise.com/us/) — take: one short confident proposition, oversized type on calm paper, ONE primary CTA, generous whitespace rhythm. Never take: financial claims, brand green, its exact grid.
- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) — take: grouped controls with hairline separators, bottom-rising sheets, 44px targets, system typography, reduced-motion respect. Never take: iOS chrome (nav/tab bars) into this web product.
- [Google Meet](https://meet.google.com/) — take: quiet top bar, large centered stage, compact bottom dock, controls where hands expect them. Never take: cameras, participant grids, any video UI — PlayCall is text-first.
